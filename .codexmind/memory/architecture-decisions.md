# Architecture Decisions — NativeMods 3.29 (`1.2.0`)

> Living decision log for the NativeMods 3.29 script extender, Client SDK (`1.2.0`, C ABI `0.6.0`), Managed Host, Server Bridge (`1.2.0`), Asset Pipeline (`DatPatchMerger` + `.fmt`/`.ast`/`.smd` 3D pipeline), `nativemods` CLI, PE32+ Patcher, and native opt-in Waypoint integration. **ALL 5 PHASES (`0.2.0` → `1.2.0`) COMPLETE.**

## 1. Frozen-Target Scope (3.29.3c & 3.29.3d Only)

- LocalExile targets Path of Exile 3.29.3c and 3.29.3d exclusively.
- Symbols are stored in static per-build Address Library JSON files (`data/addresses/3.29.3d.json`: **`447` symbols**, **`373` offsets**, **`18` constants** — `447/447` verified; `data/addresses/3.29.3c.json`: **`447` symbols**, **`360` `null` unverified**, **`87` verified/shared**) validated against `data/addresses/address-library.schema.json`. All `kind: "vtable"` entries store `"expectedBytes": null` for `DYNAMIC_BASE` ASLR safety. (`world.object_map` corrected from stale `0x8d8` → `0xa18` in `0.4.0`.)
- `scripts/generate-address-table.py` (`--check` enforced by CMake) code-generates `src/native-shim/src/address_table.cpp` directly from JSON so zero hardcoded RVAs exist in `client_host_shim.cpp` / `version_proxy.cpp` / `phase4_services.cpp` / `phase5_services.cpp` and `SimulatedNativeBridge` aligns all `447` symbol names.
- `scripts/port-address-library.py` automates blind cross-build porting across all `447` symbols (`code`, `data`, `vtable`, `import_slot`, `global_ref`), verified **`447/447` (100%)** exact RVA & byte parity via `--verify-self` on `3.29.3d` `Game.exe`.
- Because the binary has `DYNAMIC_BASE` (ASLR), all addresses are stored as **RVAs** relative to image base `0x140000000` and resolved dynamically against the loaded module base with expected-byte checks before detour installation.

## 2. Three-Layer Client Architecture

1. **Universal PE32+ Patcher (`src/LocalExile.Client.Patcher/`)**:
   - Cross-platform .NET 10 library and CLI.
   - Moves the existing PE import directory into a new section (using the verified 136 bytes of PE header slack) and appends an import descriptor for `LocalExile.ClientHost.dll`, preserving existing imports, data directories, and Authenticode layout with byte-for-byte reversible unpatching (`NMUNPAT1`).
   - Supports `version.dll` proxy deployment as an explicit fallback (requires `WINEDLLOVERRIDES=version=n,b` under Wine/Proton).
2. **Native Script Extender Shim (`src/native-shim/` → `LocalExile.ClientHost.dll`, C ABI `0.6.0`)**:
   - C++20 Win64 DLL exposing **C ABI `0.6.0`** (`NM_ABI_VERSION = 0x00000600u`, `NmAbiTable = 1168 B` / `145` fn ptrs `0..144`, `NmHookContext = 128 B`, `NmNativeCallDesc = 104 B`, Phase 1/2/4 structs, plus Phase 5 slots `139..144`: `StackSetU32WireEnabled`, `StackSetFormatMillionsEnabled`, `StackSetEntityOverride`, `UiSetCompactSocketsEnabled`, `WorldPlayEffect`, `WorldCreateClientObjectEx`, and **`162`** `.def` exports).
   - `HookEngine`: full C++20 x64 instruction-length decoder + ±2 GB RIP-relative relocator + shared multi-mod `TargetChain` (`PRE`/`POST`, `SkipOriginal`, `>= 50 ms` quiescent reclamation, DWARF `.eh_frame` & Win64 `RUNTIME_FUNCTION`+`UNWIND_INFO` exception unwind + RAII `ActiveCallGuard`) + `nm_call_native_guarded` (up to 8 mixed int/float args inside `0xE06D7363` SEH/C++ wall).
   - Owns build recognition, Win64 game-allocator wrapper (`0x2c8cf60` + 16B header / `0x2c8ca30`, plus raw mimalloc `0x248` align `16` for `ClientEntity`), `MsvcWString` & `ScopedOverlayIndex` RAII reclamation, main-thread frame queue, 15 UTF-16 text extensions (12 BOM + 3 no-BOM `.sm`/`.mat`/`.amd`), live UI + Phase 4 programmatic rich controls, tooltips, stash affinity, live native `Extend` registries (`alignas(16)` `GealBuiltinEntry`, 7-slot MSVC `_Func_base`, `0xAE` free native ruleset), **Phase 5 opt-in `u32` stack deserialization (`0xFFFF + u32`) & millions formatting, compact 6-socket rendering (`SocketOverlay::SetCellSide`/`Rebuild`), and live world VFX/extended object spawn**, stock/pre-game screen & stash-tab hooks, suppressible keyboard/mouse hooks, hovered/cursor item inspection, live `ClientWorld+0xa18` `EntityManager` + 14 components + `StatsComponent+0xf0` + `AreaEntered`/`AreaLeft` + `ItemFilter` + `FollowCamera`/`CameraController`, `IClipboardService`, `ReadStockGameFile`/`Invalidate`, `SendRaw` (`1..65536`), `0x02FC+` opcode groups (`0x29a7710`), and chat suppression.
   - Boots a private self-contained `win-x64` .NET 10 `hostfxr`/CoreCLR runtime off the game thread, deferring `AutoLoadClientMods` onto the game-thread queue (guarded under `NativeEntryPoint.Gate`).
3. **Managed Host & Public SDK (`src/LocalExile.Client.Host/`, `src/LocalExile.Client.Sdk/`, `1.2.0`):**
   - `LocalExile.Client.Sdk` (`VersionPrefix=1.2.0`, `SdkVersion.Current == "1.2.0"`, `ProtocolVersion == 1`, `NativeShimConstants.AbiVersion == 0x00000600u`, NuGet-packable via `./scripts/pack-sdk-nuget.sh`) compiles client mods with zero dependency on Host internals (`Engine` incl. `IStackExtensionService`, `IUiService.SetCompactSocketsEnabled`, `IPicture`/`IScrollableFrame`/`ITabContainer`/`IComboBox`/`IListBox`, `IUiItemGrid`, `ITooltipService`, `IStashAffinityService`, `IScreensService`, `IInputService`/`IKeybindRegistry`, `IHoverService`, `IToastService`, `IPreGameService`, `IWorldService.{PlayEffect, CreateClientObjectEx}`, `IAudioService` 2D/3D spatial audio, `IStatsService`, `IGameLifecycle`, `IItemFilterService`, `ICameraService.TryWorldToUiPosition`; live native `Extend` incl. `IGealBuiltinRegistry`, `IRulesetRegistry.{FirstFreeNativeRulesetId, IsNativeSlotFree, RegisterNative}`, `IUiControlRegistry`, `IContentRegistry.{RowMap, ContentRowMapDigest, TryResolveRow}`; `Net`, `Raw`, `IAddressLibrary`).
   - `ClientHostRuntime` auto-mounts `Mods/Client/.merged-cache/` at `t=0` before any client mod loads (excluding `content-row-map.json` from game file overlays), parses `content-row-map.json` onto `IContentRegistry`, and advertises `ContentRowMapDigest` + `"content.row-map"` + `"stacks.u32"` in `ClientHandshake`.
   - `ClientModLoader` loads each mod in a shadow-copied collectible `AssemblyLoadContext`, enforces manifest `Enabled`, `Depends` (Kahn topological sort), and `PayloadHash` (assembly SHA-256 separate from `BundleSha256`), rejects duplicate `ContentRegistry` registrations, tracks `ScopedGameServices` disposal across all services (including automatic per-mod `ICameraService.SetZoomOverride`, `IStackExtensionService`, compact sockets, and Phase 4 tooltip/affinity/Extend cleanup on ALC unload), and isolates per-mod faults.
   - `INativeBridge.IsOnGameThread` uses `[ThreadStatic] s_inNativeGameFrame` across all native-to-managed game-thread callbacks, and `ClientHostRuntime._subscribedUiEvents` + `ScreensService.SyncSlotAttachments` clean up native controls without leaking or double-freeing across panel switches and zone teardown.

## 3. Dual-Side Mod Model & `ServerBridge 1.2.0`

- Showcases (`examples/DualMod.IdolsAndGearVault/`, `examples/DualMod.ContentPackDemo/`, `examples/DualMod.SiphonOrb/`, `examples/DualMod.LootTools/`, `examples/DualMod.StashQol/`, `examples/DualMod.SkipCampaign/`, `examples/DualMod.MaxwellPet/`, `examples/DualMod.HarvestGarden/`) demonstrate rich dynamic UI / grids / tooltips / custom stash affinity / live `Extend`, composable `.datpatch.json` content packs, natural currency world drops, and dual-side `Shared/`/`Server/`/`Client/` architecture.
- **Primary Transport (`HostRuleset`, S→C `0x2c9` / C→S `0x2ca` filter-hook `0xA0`)** + **Fallback Transport (`ChatFallback`, S→C `0x17` `##NM ` / C→S `0x15`)**, plus **Pre-Game Login TCP option injection** (`C→S 0x12` `CreateCharacter.S78` `|nm:k=v&...`). Note: on `3.29.3d`, `rulesets.creator_table[0xA0]` is stock-occupied, so `0xA0` is strictly a pre-dispatch `0x02C9` filter-hook transport while native ruleset registrations use verified free slots (`IRulesetRegistry.FirstFreeNativeRulesetId = 0xAE`).
- **`ServerBridge 1.2.0` (`src/LocalExile.Client.ServerBridge/`, NuGet-packable):**
  - `ClientBridgeHost`: async `On<T>` / `OnClientReady`, `HostChannelId`, `IsClientReady`, `HasMod`, `HandlerError` isolation, `ServerUiWindowHandle`, `IClientCommandBatch`, plus `ServerContentRowMap` + `ClientBridgeOptions.{ExpectedContentRowMapDigest, ContentRowMap}` + `IClientSession.IsContentRowMapDigestMatched` + `ContentRowMapDigestMismatch` event.
  - **Tier 1 `0.3.0`, `0.4.0` & `1.2.0` (`ServerBridgeTier1.cs` / `ServerBridgePhase2.cs` / `ServerBridgePhase4.cs` ↔ `ServerBridgeTier1Handler.cs`):** `IClientPhase1Session`, `IClientPhase2Session`, and **`IClientPhase4Session`** (tooltips, stash affinity, rich UI / `IUiItemGrid`, 3D spatial audio, world VFX, compact sockets, opt-in `u32` stacks) with ref-counted subscriptions and automatic teardown.
  - `LocalExileGatewayHost.Create` / `Attach`: integrates `LocalExile` Core Hooks Part 1 + Part 2a + Part 2b + **Part 2c** (`feat/nativemods-phase0-core-hooks` `c0392f414` cleanly rebased atop `origin/main` `affb3b104`: `Client.For(player)`, `GameEvents.*` incl. Part 2c `AreaInit`/`AreaClosing`/`MonsterKilled`/`PlayerDeath`/`ObjectUse`/`MapDeviceActivating`, `IPlayerWorld` progression & encounter facades, custom portals/sub-areas, `ItemCatalog`/`UniqueCatalog`/`ModCatalog`/`GemSources`/`DropPoolOverlays`/`ObjectTypes`/`MonsterCatalog`/`NpcCatalog`/`BuffRows` overlays, custom vendor recipes, `LeagueData` persistence, and `GameEventOwners` cleanup). Qualify `global::Client.For(player)` when importing `LocalExile.Client.ServerBridge`.
  - **Ground-Item Relocation Invariant (`DualMod.LootTools`):** Never relocate `WorldItem`s via `0x01B7` Teleport (leaves `InstanceGround` `_cells` stale and creates ghost labels). Always use atomic `Ground.Take` → `Ground.Add(..., justDropped: false)` + `Game.SendWorldRemoval` (`0x02BD`) + `Game.SendGroundItem(..., justDropped: false)` (`0x02BB` + `0x01A9`).
  - **Server Mod Persistence Rule:** Never write runtime files inside `Mods/Binaries/<id>/` (triggers `ModHost` auto-reload loop); persist via `AccountData`/`CharacterData`/`LeagueData` or `data/mods/`. `Mods/Client/` is outside `ModHost`'s watch root.

## 4. Waypoint, `AssetPipeline` (`DatPatchMerger` + 3D Meshes) & `nativemods` CLI (`1.2.0`)

- **Servers never push executable code.** Waypoint (`feat/nativemods-integration` `1a346cb`, opt-in off by default, WPF + Avalonia parity, EN/RU/ZH-CN, `ProxyVersionDll` default on release/Proton + `ImportTable` on source checkouts, `nativemods-host/` + `Mods/Client/` layout) validates `mod.json`, `.ui` layouts, `.datpatch.json` patches, namespace rules, and SHA-256 digests.
- **Schema-Driven Multi-Mod `.datc64` Merger (`DatPatchMerger` + `Dat64SchemaRegistry` + `data/schemas/poe-3.29-dat-schema.json`):**
  - Declarative `nativeClient.datPatches` (`DAT001..DAT009`, `NC022..NC023`, `PAY007`, `CNF007..CNF009`) let multiple independent mods share `.datc64` tables cleanly (`append` + `$ref:TableName:EntryKey`, in-place `modify` e.g. `StackSize = 65535`, 30-slot `allocateDeadStat` preserving stock `Stats[row].Id` + emitting UTF-16LE BOM+CRLF `Metadata/StatDescriptions/<mod>_custom_stats.txt`), deep-copying all variable-section arrays (`CloneRowDeep` + `VerifyNoPointerArrayAliasing`), auto-allocating `HASH32`/`HASH16`/unique `MtxTypes.__col18`, and writing deterministic `Mods/Client/.merged-cache/` + `content-row-map.json` SHA-256 digest (`DeploymentLedger.MergedCacheDigest`).
- **Generic 3D Mesh Pipeline (`LocalExile.Client.AssetPipeline.Mesh`):** `.glb` → `.fmt` v9 static mesh (`PoeFmtWriter`/`GlbToFmtConverter`/`convert-glb-fmt`), multi-bone `.ast` v7 skeleton (`PoeAstWriter`/`GlbToAstConverter`), 4-bone skinned `.smd` v3 mesh (`PoeSmdWriter`/`GlbToSmdConverter`/`convert-glb-smd`), and binary round-trip inspector (`inspect-mesh`).
- **Registry Table Policy (`DualModPackageValidator` & `Dat64SchemaRegistry`):**
  - **`22` `AppendableRegistryTables`:** `BaseItemTypes`, `ItemVisualIdentity`, `CurrencyItems`, `MtxTypes`, `MtxTypeGameSpecific`, `Pet`, `MonsterVarieties`, `NPCs`, `Chests`, `Projectiles`, `MiscObjects`, `MiscAnimated`, `HideoutDoodads`, `ExecuteGEAL`, `ClientStrings`, `Mods`, `ModType`, `BuffDefinitions`, **`MinimapIcons` (`34 B`), `BuffVisuals` (`244 B`), `NPCTalk` (`389 B`), `Words` (`64 B`)**.
  - **`2` `ClosedRegistryTables` (`NC016`/`DAT003` error):** `ItemClasses` (103-entry compiled enum) and **`Stats`** (`23,362` / `0x5b42` fixed rows — `0x5b43` is compiled `StatId::INVALID` + 4 OOB tables; custom stats use the 30-slot dead-stat pool strictly excluding row `464`, preserving stock `Id` + Route A `Metadata/StatDescriptions/*.txt` overlays, or unbounded high-ID `StatsComponent` `0x1b3` stats).
- **`nativemods` CLI (`src/LocalExile.Client.Cli/`):** Provides `new tier1|dual|content`, `validate [--against] [--json]`, and `merge --stock --out` for mod authors and CI.
- `ModBundlePacker` (`NMB1` chunked framing `[u32 chunkLen][0xCC 0x06][payload]`) enforces **12 BOM+CRLF**, **3 no-BOM+CRLF** (`.sm`, `.mat`, `.amd`), plus the case-insensitive **`art/uiimages1.txt` no-BOM** exception, and `PoeContentHash.MurmurHash2` matches `PoeHashing.Hash32` (`Encoding.UTF8`).
