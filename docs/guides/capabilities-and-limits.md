# Capabilities, Limits & Hard Engine Ceilings

**Mandatory pre-flight reference for human mod authors and AI coding agents.** Every boundary below is empirically verified against Path of Exile **3.29.3d** / **3.29.3c** disassembly and live Proton runs. Violating these invariants causes crashes, infinite layout hangs, validator rejections, or memory leaks.

## Hard Engine Ceilings & Critical Invariants

### 1. Closed `Stats` Table, Dead Slots and High-ID Stats

- **`Stats.datc64` MUST remain strictly `23,362` (`0x5b42`) rows.**
  - Appending even 1 row produces 1-based `StatId 0x5b43`, which collides with compiled `StatId::INVALID` (`0x5b43`) across 35+ inlined call sites, triggers `"Stats enum is out of sync"` (`0x1428eed00` / `0x143648bd0`) at character select, and causes unchecked heap out-of-bounds reads/writes in `StatDescriptionList`, `StatValues`, `g_statInfoTable`/`g_statTopoOrder`/`g_statTopoInv`, and `StatCalc::m_hasStatBitset`.
  - `DualModPackageValidator` enforces `Stats` and `ItemClasses` in `ClosedRegistryTables` (`NC016` error).
- **Three safe custom-stat mechanisms:**
  1. **Unbounded high-ID `StatsComponent` stats (`>= 0x10000`):** Wired over `StatsComponent` (`0x1b3` varint) and readable/writable via `IStatsService.ReadStat(entityId, 0x10001)` / `GetAllStats` and Tier 1 `session.Phase2.QueryStatAsync(0x10001)`.
  2. **Dead stock stat slot allocation (30 verified slots):** `old_do_not_use_*` / `currently_unused_*` rows in stock `Stats.datc64` (keeping stock `Id` unchanged so LocalExile's `Stat.Checksum` passes, paired with Route A `Metadata/StatDescriptions/*.txt` overlays; **never** reuse row `464`).
  3. **In-place non-ID column edits** on existing `Stats.datc64` rows.

### 2. `.datc64` `foreignrow[]` Variable-Section Aliasing Rule

PoE 3.29's `.datc64` loader resolves `foreignrow[]` array elements **in-place inside the loaded variable-data section**, overwriting `{u64 row_index, u64 0}` with `{void* row_ptr, void* target_table_ptr}` row-by-row.
- If an appended row cloned via `CloneRow(templateRow)` shares a `foreignrow[]` variable-section offset with the template row, processing the appended row treats the already-resolved pointer pair as a raw row index, writes `table_ptr = NULL`, and crashes at `Game.patched.exe + 0x129838` (`[NULL + 0x28]`) on town entry.
- **Invariant:** Never alias any `foreignrow[]` variable-section offset across rows. Deep-copy or clear every `foreignrow[]` array column (`Pet.__col7` @36, `Pet.Skills` @68, `BaseItemTypes` 11 array columns, `ItemVisualIdentity` 16 array columns) to fresh offsets via `Dat64TablePatcher.SetForeignRowArray` (handled automatically by `MaxwellDatPatcher` and `CurrencyDatPatcher`). Also enforce unique `MtxTypes.__col18` (@137).

### 3. Exact Client Text Encodings (12 BOM+CRLF vs. 3 + 1 No-BOM)

| File Extensions / Paths | Required Encoding | Helper |
|---|---|---|
| `.ui`, `.ot`, `.otc`, `.it`, `.itc`, `.ao`, `.aoc`, `.act`, `.epk`, `.ddt`, `.pet`, `.trl` *(12 extensions)* | **UTF-16LE with BOM (`0xFF 0xFE`) + CRLF (`\r\n`)** | `ClientTextEncoding.EncodeUtf16LeBomCrlf`, `EncodeTextForPath`, `RegisterVirtualTextFile`, `ModBundlePacker.EncodeClientText` |
| `.sm` (v6), `.mat` (v4 JSON), `.amd` *(3 extensions)* + **`art/uiimages1.txt`** *(case-insensitive)* | **UTF-16LE without BOM + CRLF (`\r\n`)** | `ClientTextEncoding.EncodeUtf16LeNoBomCrlf`, `EncodeTextForPath`, `ModBundlePacker.EncodeClientTextNoBom`, `PoeAstWriter.BuildAmd` |
| `mod.json`, `settings.json`, `manifest.json` | UTF-8 | Standard JSON |

`DualModPackageValidator` flags stray BOMs in `.sm`/`.mat`/`.amd` with **`ENC001`** Error (`WaypointModInstaller.Install` auto-normalizes `ENC001` during `DeployClientFiles`).

### 4. Namespace Rules vs. `replaces`

- Every new overlay asset in `payloadDir` (`client/`) **must** live under a `Mods/<namespace>/` segment (case-insensitive), where `<namespace>` matches either:
  - the full `mod.json` `id` (e.g., `id: "maxwell"` → `Mods/Maxwell/`), **or**
  - the last hyphen-delimited segment of `id` (e.g., `id: "harvest-garden"` → `Mods/Garden/`).
- **Hyphenated ID trap (`PAY003`):** If `id = "maxwell-pet"`, `Mods/Maxwell/` fails validation because the last hyphen segment is `"pet"`, not `"maxwell"`. Use `id: "maxwell"` or `id: "pet-maxwell"`, or place files under `Mods/maxwell-pet/`.
- Any file outside `Mods/<namespace>/` (such as patched `Data/*.datc64` or a deliberate stock override) **must** be explicitly listed in `nativeClient.replaces` so Waypoint audits it and detects `CNF001` cross-mod conflicts.

### 5. `ModHost` Auto-Reload Loop Hazard (Server Mods)

- LocalExile's server `ModHost` watches `Mods/Binaries/<id>/` and triggers a hot-reload whenever any file inside a mod's binary folder changes.
- **Never write runtime state, caches, or logs into `Mods/Binaries/<id>/`**, or your server mod will reload endlessly.
- Persist server mod state via LocalExile's `IPlayerWorld.AccountData` / `CharacterData` APIs or write files under `<LocalExileRoot>/data/mods/<id>/`.
- NativeMods' client runtime files under `Mods/Client/` (`.extender-state.json`, `.nativemods-ledger.json`, `keybinds.json`, `.merged-cache/`) sit outside `Mods/Binaries` and do not trigger `ModHost` reloads.

### 6. Threading, `StateStack::PassA` OS TID Migration & Exception Wall

- All UI (`IUiService`), stats (`IStatsService`), world (`IWorldService`), filter (`IItemFilterService`), camera (`ICameraService`), and native calls must run on the game thread (`IGameServices.Frame` or `context.Scheduler.RunOnGameThread(...)`).
- **OS TID Migration Caveat (Proven in Spike R1):** Live 3.29.3d Proton runs proved `StateStack::PassA` (`0x1528f40`) normally runs on one OS thread (`tid=352`) but migrates across OS threads (`tid=468`, `tid=472`) during Job2 transitions. **Never cache `GetCurrentThreadId()` or use `[ThreadStatic]` assuming a single immutable game thread.**
- Use `context.Scheduler.IsOnGameThread` (backed by active native-to-managed scope `s_inNativeGameFrame` across `Frame`, `Drain`, `Ui*`, `RulesetRx`, `ChatRx`, `OpcodeRx`) and `context.Scheduler.RunOnGameThread(...)`.
- **`DeadlockDetector` (`0x140e3ed10`):** Never block the game thread with synchronous I/O or `.GetAwaiter().GetResult()`. NativeMods boots CoreCLR off-thread and defers `AutoLoadClientMods` onto the game thread via `EnqueueGameThread`.
- **Exception Wall:** Every native call crosses `nm_call_guarded`, catching Win64 SEH and MSVC C++ exceptions (`0xE06D7363`). `ClientModLoader` isolates managed exceptions; a mod exceeding `MaxModFaults` (default `3`) on `Frame` is disabled automatically without crashing the client or other mods.

### 7. Collectible `AssemblyLoadContext`, STJ Pinning & Disposal Tracking

- `ClientModLoader` shadow-copies `<id>.Client.dll` into a collectible `AssemblyLoadContext(isCollectible: true)` for zero-restart hot reload.
- **On .NET 10, `System.Text.Json.JsonSerializer` permanently pins collectible ALCs** via `JsonSerializerOptionsUpdateHandler` strong metadata caches (`UnloadedCleanly == false`) — even when allocating a brand-new `JsonSerializerOptions`.
- **Mandatory rules:**
  1. Pass typed records through `context.Net.Send<T>` / `context.Net.On<T>` (automatically routed through zero-static-cache **`CollectibleJsonCodec`** in `LocalExile.Client.Sdk.Protocol`) or call `MessageCodec.GetJsonOptionsForType(typeof(T))`.
  2. Register every subscription, overlay, window, slot button, keybind, and hook handle with `context.TrackDisposable(...)`.
  3. Unsubscribe `context.Game.Frame -= OnFrame` and stop active audio channels inside `IClientMod.Unload()`.
  4. `ScopedGameServices` wraps `Lifecycle`, `Rulesets`, `Opcodes`, `Chat`, `Scripts`, `Audio`, `World`, `Screens`, `Input`, `Hover`, `Toasts`, `PreGame`, `ItemFilter`, and `Camera` to detach leaked delegates and restore camera zoom overrides automatically on unload.

### 8. HookEngine 8-Arg Chain Limit vs. Raw Detours

- **`<= 8` Win64 Arguments:** Use `IRawMemory.InstallHookChain` / `HookEngine::install_inline_chain` for shared multi-mod Pre/Post chaining with DWARF `.eh_frame` / Win64 `RUNTIME_FUNCTION`+`UNWIND_INFO` C++ exception unwind support and multi-chain `expectedBytes` tail verification beyond `stolen_len`.
- **`> 8` Win64 Arguments:** `install_inline_chain`'s generic dispatcher forwards only `args[0..7]`. Hooking a `> 8`-arg function — such as 10-arg `world.client_world_init_area` (`0x141653ee0`, `rcx/rdx/r8/r9` + 6 stack args) — via a chain hook drops `arg8`/`arg9` and triggers an immediate `0xC0000005` access violation on area entry. Always use a typed raw `install_inline` detour forwarding all parameters when a native target takes `> 8` arguments.
- **Leaf / Short Thunk Guards:** `compute_stolen_length` rejects `< 14 B` leaf functions terminating early unless an earlier conditional branch jumps past the terminator, and rejects mid-instruction internal jump targets.

### 9. Slab-Pool Control Destroy and `.ui` Parser Crash Traps

- **Slab-Pool Destroy Hazard:** Most PoE `Control` objects are slab-allocated (`[control + 0x08] != 0`). Destroying them via `vtbl[8]` (heap deleting destructor) corrupts the slab pool. NativeMods' `ui_destroy_control` calls `Control::ReleaseOrDestroy` (`0x18b6810`) when `+0x08 != 0` and falls back to `vtbl[8]` only for heap controls (`+0x08 == 0`).
- **Mandatory `.ui` Linter Rules (`UiLayoutLinter`):**
  - **`UI002` (Fatal parse error):** Never start a `.ui` file on byte 0 with `<DEFINITIONS>` — always begin with a `//` comment or blank line.
  - **`UI006` (Unknown control):** Use only the **47 verified 3.29.3d stock controls** or custom controls declared in `nativeClient.customControls` and registered natively via `IUiService.RegisterControl` / `IUiControlRegistry` (live-wired into `g_uiControlFactoryMap` `0x14475e990` in `1.1.0`).
  - **`UI008` (100% CPU infinite layout hang):** **Never set `margin` on a `Picture` directly inside a `StackLayout`.** Place an empty spacer `begin Frame` (`size = 10, 12;`) after the `Picture` instead.
  - **`UI010` / `UI013` (`error: ":" expected`):** Never invent unknown properties on stock controls.
  - **`UI016` (Uncaught `0xE06D7363` crash):** Every sibling control under the same parent container MUST have a unique `id`.

### 9.5 Phase 4 (`1.1.0`) Native ABI Invariants (`GealBuiltinEntry`, MSVC `_Func_base`, Ruleset `0xA0`)

- **`GealBuiltinEntry` 16-Byte Alignment (`movaps`):** `geal.builtin_register_entry` (`0x141de9780`) loads entries via `movaps xmm0, XMMWORD PTR [rdi]` (`0x141de9858` / `0x141de9870`). Any `GealBuiltinEntry` or game-bound 16B/SBO struct passed into `geal.*`/`ui.*` MUST carry `alignas(16)` (an 8B-aligned pointer causes `#GP` `0xC0000005` under SEH).
- **Exact 7-Slot MSVC `std::_Func_base` Vtable Order:** Every native shim functor placed inside a game `std::function` (GEAL `FuncWrapper` and `g_uiControlFactoryMap` custom control factories) MUST match VS2019 `std::_Func_base` (`0x143031688`): `[0]=_Copy`, `[1]=_Move`, `[2]=_Do_call`, **`[3]=_Type`, `[4]=_Delete_this`, `[5]=_Get`, `[6]=~_Func_base(flags)`**. Swapping `_Type`/`_Delete_this` corrupts destruction on map erase or script unload.
- **`rulesets.creator_table[0xA0]` Occupied Collision:** On `3.29.3d`, slot `0xA0` (`0x14475e170`, vtable `0x14348ba50`) is **occupied by a stock ruleset** (`68` occupied / `107` free across `0x00..0xAE`). `0xA0` remains valid strictly as the `0x02C9` filter-hook host transport (`DefaultHostChannelRulesetId`), whereas native `rulesets.creator_table` registrations (`IRulesetRegistry.RegisterNative`) reject `0xA0` (`NM_ERR_ALREADY_EXISTS`) and default to **`IRulesetRegistry.FirstFreeNativeRulesetId` (`0xAE`)** (other high free slots: `0xAA`, `0xA9`, `0xA3`, `0x9C`, `0x90`).

### 10. `WorldItem` Zero-Ghost-Label Relocation Rule

When moving or merging ground items on the LocalExile server (Loot Magnet / Loot Merger):
- **NEVER send `InstanceProtocol.Teleport` (`0x01B7`)** on a `WorldItem`. `InstanceGround` does not update its spatial `_cells` grid, breaking pickup reach and leaving permanent ghost labels on the client.
- **ALWAYS use atomic relocation:**
  1. `Ground.Take(id, item)`
  2. `Ground.Add(relocated, origin.By, origin.Shared, justDropped: false)`
  3. `Game.SendWorldRemoval` (`0x02BD`)
  4. `Game.SendGroundItem(..., justDropped: false)` (`0x02BB` + `0x01A9`)
- Validate allocation (`origin.Shared || ReferenceEquals(origin.By, player)`), lockstep admission (`!LockstepClient || WorldOutput.Has(id)`), and skip quest/start-weapon drops (`IsStartWeapon` + `TutorialObjects.DropKey`).

### 11. Additional Mandatory Rules

- **Item Filter Directory:** PoE 3.29 **always** enumerates `.filter` files from `Documents\My Games\Path of Exile`, ignoring `Client\config.json` subfolder redirection.
- **`global::Client.For(player)` Qualification:** `LocalExile.Client.ServerBridge` defines `LocalExile.Client.ServerBridge.Client`. Inside LocalExile Gateway Roslyn entry files that import `LocalExile.Client.ServerBridge`, always qualify LocalExile's core class as `global::Client.For(player)`.
- **`.ot` Pet Inheritance & Serialized Components:** Use **singular** `Metadata/Pet/...` (no `.ot` suffix in `Pet.Id`), extend `"Metadata/Pet/Pet"`, and add **zero extra serialized components** (no `StateMachine`, etc.) so `PetObject.BaseComponents` wire layout (`S→C 0x02bb`) stays intact.
- **Security & Package Limits:** Servers NEVER push executable code to clients. `DualModPackageValidator` enforces `MaxManifestBytes = 128 KB`, `MaxPackageBytes = 64 MB`, `MaxPackageFiles = 2000`, zero symlinks/reparse points, and zip-slip rejection. `rawAccess: true` requires `rawAccessJustification` (`NC008`) and `InstallOptions.AllowRawAccess == true`.
- **Proton `pressure-vessel` `/tmp` Trap:** `umu-run`'s `steamrt4` container does not mount host `/tmp`. Stage temporary Proton test artifacts under `<LocalExileRoot>/data/` (and clean up in `trap EXIT`).
